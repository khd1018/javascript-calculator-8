# javascript-calculator-precourse

## 문자열 계산기

### 기능 목록

- 구분자를 기준으로 문자열을 분리할 수 있다.

  - 구분자 : 쉼표(,) 또는 콜론(:)

- 숫자의 합을 구할 수 있다.

- 커스텀 구분자를 지정할 수 있다.

  - 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용

- 사용자 입력값이 유효한지 확인할 수 있다.

  - 구분자와 양수로 구성된 문자열
  - 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션 종료

- 사용자가 커스텀 구분자를 입력했는지 확인할 수 있다.

- 첫번째 문자가 숫자인지 판별할 수 있다.

### 예외 상황

사용자가 잘못된 값을 입력하는 경우

- 빈 문자열을 입력하는 경우
- 숫자가 없는 경우
- 잘못된 형식으로 커스텀 문자열을 지정하는 경우
- 잘못된 구분자를 사용하는 경우 (+구분자가 없는 경우)
- 음수를 입력한 경우
- 커스텀 구분자가 기존 구분자와 중복되는 경우
